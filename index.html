📱 സ്കാൻ ചെയ്ത് ഉത്തരം നൽകൂ

പങ്കെടുക്കുന്നവർക്കുള്ള ലിങ്ക്

⚠️ ഈ ഫയൽ ഇപ്പോൾ കമ്പ്യൂട്ടറിൽ നിന്ന് നേരിട്ടാണ് തുറന്നിരിക്കുന്നത്. ഫോണുകളിൽ ലിങ്ക് പ്രവർത്തിക്കാൻ, ഈ HTML ഫയൽ ആദ്യം Netlify Drop (app.netlify.com/drop) അല്ലെങ്കിൽ GitHub Pages പോലുള്ള സൗജന്യ സൈറ്റിൽ അപ്‌ലോഡ് ചെയ്ത് ആ വെബ് വിലാസത്തിൽ തുറക്കുക. അപ്പോൾ ഇവിടെ ശരിയായ ലിങ്കും QR-ഉം വരും.
ലിങ്ക് WhatsApp-ൽ ഷെയർ ചെയ്യുകയോ QR സ്ക്രീനിൽ കാണിക്കുകയോ ചെയ്യാം. ലോഗിൻ ആവശ്യമില്ല. ഈ സ്ക്രീനിൽ ഇപ്പോൾ കാണിക്കുന്ന ചോദ്യമാണ് എല്ലാവരുടെയും ഫോണിൽ തെളിയുക.
പുതിയ സെഷന് പഴയ ലിങ്ക് ഒഴിവാക്കാൻ "പുതിയ ലിങ്ക്" ഉപയോഗിക്കുക.
